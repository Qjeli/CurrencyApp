1. Скопируйте файл `.appx` или `.appxbundle` на целевой компьютер
2. Дважды кликните на файл
3. Windows автоматически откроет App Installer
4. Нажмите кнопку **"Install"**
5. Дождитесь завершения установки
6. Приложение появится в меню "Пуск" → "CurrencyApp"

Если файл просит сертификат:
1. Дважды нажмите на CurrencyApp_Certificate.pfx
2. Нажмите "далее"
3. Оставьте пароль пустым (или введите password123)
4. Выберите "Автоматически выбрать хранилище на основе типа сертификата"
5. Click "Finish"
